# grok-video

보고대상사건 기반 교육 영상 생성 프로젝트

## 개요
보고대상사건을 요약하고 2~3분 분량의 교육 영상을 생성하는 수동 워크플로우입니다.

- 요약 → 스토리보드 → 3D 레고 스타일 이미지 생성
- 이미지투비디오 (480p / 9:16 / 6초)
- 나레이션(ElevenLabs) + BGM(Google Flow Music)
- 인트로/아웃트로는 AI 영상 생성 없이 이미지 기반 통제형 편집

## 사양
- 해상도: 480p
- 비율: 9:16
- 클립 길이: 6초
- 스타일: 3D 레고 블록 질감
- 특정 발전소명 사용 금지 (설비명은 유지)

## 폴더 구조
- `templates/`: 스토리보드, 프롬프트, 나레이션 템플릿
- `projects/`: 사건별 작업 폴더
- `assets/`: 생성된 이미지/영상 자산
- `docs/`: 스타일 가이드 및 문서

## 사용 방법
1. 보고대상사건을 Grok에게 전달
2. 생성된 산출물을 `projects/<사건명>/` 아래에 저장
3. 커밋트로 중간 동기화
